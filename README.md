Delta Force Companion

Your battlefield companion — maps, loadouts, resources and updates in one place.

Delta Force Companion is an unofficial fan-made Android app designed to give players quick access to useful Delta Force resources.

Features

- 🗺️ Interactive Maps: Zero Dam, Layali Grove, Space City, Brakkesh and Tide Prison.
- 🔫 Weapon Loadouts: Resources for Operations and Warfare.
- 🏢 Headquarters: Quick access to useful game resources.
- 📢 Announcements & News: Game-related updates and information.
- 🎮 Community: Useful community links.

Download APK

1. Visit the "GitHub Actions page" (https://github.com/KALUBOT/Delta-Force-Companion-App/actions).
2. Open the latest successful build.
3. Scroll to Artifacts.
4. Download "DeltaForceCompanion-APK".
5. Extract the ZIP and install the APK.

Technology

- Kotlin
- Native Android
- Gradle
- Java 17
- Android SDK 35

Build

The project uses GitHub Actions to compile the Android application.

To build manually, open Actions and select Build Delta Force Companion APK → Run workflow.
