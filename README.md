🎯 YOUR NEXT DEPLOYMENT STARTS HERE

Delta Force Companion is an unofficial, fan-made Android application designed to bring useful Delta Force resources together in one place.

Whether you're planning your next Operations run, preparing a weapon setup for Warfare, or checking the latest game information, your essential companion resources are just a tap away.

Less searching. Better preparation. More time on the battlefield.

📲 DOWNLOAD THE APP

Get the latest available Android build through GitHub Actions.

1. Open the "Actions page" (https://github.com/KALUBOT/Delta-Force-Companion-App/actions).
2. Select the latest successful Build Delta Force Companion APK workflow.
3. Scroll down to Artifacts.
4. Download "DeltaForceCompanion-APK".
5. Extract the ZIP and install the APK.

«GitHub Actions artifacts may expire. Check the latest successful workflow for the available build.»

👨‍💻 BUILD FROM SOURCE

Developers can explore the source code and build the application using the project's GitHub Actions workflow.

1. Open the repository's Actions tab.
2. Select Build Delta Force Companion APK.
3. Select Run workflow, if available.
4. Wait for the build to complete.
5. Download the APK from the workflow artifacts.
